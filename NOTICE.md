# Attribution

The inference implementation retains components from the Appa-based research
code and the following referenced work:

- Diffusion preconditioning: Karras et al., https://arxiv.org/abs/2206.00364
- Moment-matching guidance: Rozet et al., https://arxiv.org/abs/2405.13712
- Predictor-corrector sampling: Song et al., https://arxiv.org/abs/2011.13456
- Sampling utilities: https://github.com/francois-rozet/azula
- Numerical solver: https://github.com/probabilists/zuko/
- Neural network components: https://github.com/vsitzmann/siren
- Swin components: https://github.com/microsoft/Swin-Transformer

The source snapshot did not provide a project-wide license. This notice does
not grant redistribution rights. Data, pretrained weights and installed
dependencies retain their own distribution terms.
